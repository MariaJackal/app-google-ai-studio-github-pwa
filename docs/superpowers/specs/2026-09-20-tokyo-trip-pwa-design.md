# 東京・富士山旅程 PWA 設計

## 目標

把 `日本行程.txt` 整理成手機優先、日式極簡的旅遊小工具，支援六日行程、即時天氣、導航、導遊補充、航班／住宿／緊急資訊與本機記帳。

## 產品結構

- `行程`：以日期切換行程，使用時間軸呈現景點、餐廳、交通與住宿；每個節點提供 Google Maps 導航與 Transit 查詢。
- `導遊筆記`：集中呈現景點故事、移動攻略、Tabelog 區域查詢、必點菜單、必買伴手禮與預約提醒。
- `工具`：航班 FD234／FD235、住宿與預約代號、緊急電話、JPY／TWD 記帳。

## 視覺方向

採用「朱砂暖紙」：米白紙張作為主背景、朱砂紅作為主要強調色，青磁色用於天氣與資訊狀態，金色用於美食與伴手禮標籤。手機以單欄閱讀為主，桌面則限制寬度並置中；底部導覽遵守安全區域。

## 資料與外部服務

- 行程內容以靜態資料保存在 `app.js`，不需要登入或後端。
- 天氣使用 Open-Meteo 公開 forecast API；依每日主要地點逐日查詢，只請求目前可預報範圍，最近一次成功資料保存到 `localStorage`。
- 導航與轉乘使用 Google Maps URL；Tabelog 使用區域推薦／搜尋頁連結，不抓取網站內容。
- 預約代號與記帳資料只保存在瀏覽器的 `localStorage`。

## 錯誤與降級

- 網路不存在或天氣資料尚未開放時，天氣卡顯示「等待更新」，不阻塞行程使用。
- 外部連結以新分頁開啟，App 仍留在原本的行程位置。
- 所有表單欄位有原生標籤、可鍵盤操作，記帳輸入需有項目與金額。

## 驗證結果

- `node --check app.js` 通過。
- 已在手機尺寸瀏覽器確認日期切換、導遊筆記分頁、工具分頁、預約欄位與新增／刪除記帳。
- 已確認 Open-Meteo 請求能成功載入可預報日期；超出範圍的日期不會造成整頁錯誤。
- `manifest.webmanifest`、`sw.js`、favicon 與相對路徑可供 GitHub Pages 使用。
